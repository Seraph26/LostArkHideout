# Candidate Comparison Foundation Checkpoint

This checkpoint contains only the isolated roster foundation for the Character Comparison/New Additions work.

- Main Group remains capped at 8 by the existing application.
- New Additions are stored separately and capped at 8.
- Main Group cards receive an informational `Main Group` tag and Hide/Show control.
- New Addition cards mirror the existing character-card presentation and receive a `New Addition` tag, Refresh, Hide/Show, and Remove controls.
- Hidden status is persisted separately from character membership.
- No optimizer integration has been enabled yet in this checkpoint.
- Frozen hover, arrow, formatting, and validated optimization behavior have not been intentionally changed.
